This is an MCP server that has a search tool to find restaurants.

It is now using the streamable protocol.

To run this, you can just run this project as a Spring Boot application by running the `GfrestaurantsApplication.java` class.  It will run on port 8088.

Test by using MCP Inspector: https://modelcontextprotocol.io/docs/tools/inspector
- To run use this command: `npx @modelcontextprotocol/inspector`
